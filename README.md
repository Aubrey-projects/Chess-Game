# Overview

I made a 3D chess app in Kotlin for Android phones. The purpose of writing this was to introduce me to the Kotlin programming language, since this was my first time ever using it. I also got a little familiar with making a virtual phone for the first time, and converting a 2D grid into 3D world space.

[Kotlin Chess App Video](https://youtu.be/r8SL2CU_qpc)

# Development Environment

I used Android Studio to write the code and to handle my virtual phone. I also used blender to design the 3D models that I exported into my project.

I wrote the program in Kotlin. I also used various different libraries like Sceneview to render the 3D graphics, and Activity Compose, Compose Material 3, Compose UI Core, and Compose Tolling & Previews to help with user interface, etc.
